# المصحف الشريف — Al-Mushaf Al-Sharif

برنامج لتلاوة القرآن الكريم ومراجعته وتدبّره، برواية حفص عن عاصم على رسم مصحف المدينة النبوية (٦٠٤ صفحات).
يخدم المبصرين ومستخدمي قارئات الشاشة على حدٍّ سواء، ويعمل على ويندوز ٧ و٨٫١ و١٠ و١١ (٣٢ و٦٤ بت).

من تطوير فريق أمنية تكنولوجي (Omnya Technology)، هديةً للباحثين وطلاب الدراسات العليا وعموم المسلمين.

A Windows app for reading, reviewing and reflecting on the Noble Quran (Hafs from 'Asim, Madinah Mushaf, 604 pages),
built for sighted readers and screen reader users alike. Developed by Omnya Technology.

## المزايا

- التصفح بالسور والصفحات والأجزاء والأحزاب والأرباع والمنازل والركوعات، والتقليب بـ PageUp و PageDown.
- سهما تقليب للمبصر على جانبي صفحة المصحف (التالي يساراً والسابق يميناً) حسب طريقة التصفح، لا يظهران لقارئات الشاشة.
- تظليل الآيات بالسحب بالفأرة، ويتراكم التظليل مع كل سحب جديد (و Ctrl مع النقر لآية واحدة)، ثم «نسخ» ينسخ كل المظلل بترتيب المصحف.
- «النسخ المتعدد» (Ctrl+Alt+C أو من زر التطبيقات): آيات الوحدة الحالية بمربعات اختيار يقرؤها قارئ الشاشة، المسافة للتحديد و Enter للنسخ، ويُستعمل لنسخ آيات متفرقة.
- الآيات قائمة يقرؤها قارئ الشاشة آيةً آية، وتُرسم للمبصر بخط مجمع الملك فهد مع توسيط السطور كالمصحف.
- زر التطبيقات على الآية: النسخ ومعلومات الآية والمفضلة وفاصل الختمة. وعلى عنوان السورة: معلومات السورة ونسخها.
- معلومات تفصيلية عن الآية والسورة (عدد الكلمات والحروف، والاستثناءات في المكي والمدني، ومواضع التكرار).
- سجدات التلاوة الخمس عشرة مع أقوال الأئمة الأربعة، والبحث الشامل، والانتقال السريع.
- واجهة عربية وإنجليزية؛ ونص القرآن وأسماء السور تبقى بالعربية في الواجهتين.
- تكامل مباشر مع NVDA و JAWS، وصوت ويندوز المدمج عند عدم وجود قارئ شاشة.

## إضافة طبعة أخرى (مثل طبعة دار المعارف)

الطبعات تختلف في تقسيم الصفحات فقط، فتُضاف بملف فيه الآية التي تبدأ بها كل صفحة،
دون أي تغيير في الكود:

1. املأ القالب `tools/editions/dar_almaarif_template.csv` (الصفحة، السورة، الآية).
2. اسحب الملف فوق `tools/editions/check_edition.bat` ليفحصه البرنامج ويكتب تقريراً
   بالأخطاء والصفحات التي تستحق المراجعة على المصحف الورقي.
3. ضع الملف السليم في `assets/data/editions/`، فيظهر اختيار «الطبعة» في الشريط العلوي.

التفاصيل في `tools/editions/اقرأني.txt`.

## البناء

يكفي تشغيل:

```
build.bat
```

يبحث عن مترجم بالترتيب: Zig (يبني نسختي ٦٤ و٣٢ بت معاً)، ثم MinGW g++، ثم Microsoft Visual C++.
بعد كل بناء يُشغَّل الاختبار الذاتي تلقائياً، ويتوقف البناء إن فشل.
تخرج الملفات التنفيذية في `bin\`، ثم يصنع `build_installer.bat` ملف التثبيت في `release\` (يحتاج Inno Setup 6).

للتحقق من سلامة البيانات والمنطق دون فتح الواجهة:

```
bin\AlMushafAlSharif-x64.exe --self-test
```

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `src/main.cpp` | النافذة الرئيسية وقائمة الآيات والأوامر والاختبار الذاتي |
| `src/dialogs.hpp` | نوافذ الخيارات والبحث والانتقال والمفضلة والسجدات والمعلومات |
| `src/database.*` | قراءة قاعدة بيانات القرآن (SQLite) وتقسيماته |
| `src/a11y_and_config.hpp` | قارئات الشاشة والإعدادات والمظاهر اللونية |
| `src/app.rc`, `src/app.manifest` | الأيقونة ومعلومات الإصدار ومظهر ويندوز الحديث |
| `assets/` | قاعدة البيانات والخطوط وصوت تقليب الصفحة والأيقونة |
| `third_party/sqlite3/` | مكتبة SQLite (ملكية عامة) |
| `installer.iss` | ملف تثبيت Inno Setup |

تُحفظ إعدادات المستخدم في `%APPDATA%\AlMushafAlSharif\settings.json`.
